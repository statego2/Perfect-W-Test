# My Perfect Woman — Super Test (ενιαία web έκδοση)

Ένα λειτουργικό, **τοπικό-first** website σε **ένα HTML αρχείο**. Χωρίς server ή npm dependencies για τη χρήση του. Δεν παρέχει διάγνωση ή πρόβλεψη επιτυχίας σχέσης.

## Άμεση χρήση

1. Άνοιξε το **`index.html`** σε έναν σύγχρονο browser. Η εφαρμογή δεν απαιτεί internet.
2. Πάτησε **«Συνέχεια στο Super Test»**, ή διάλεξε μία ενότητα.
3. Δες το **«Προβολή του προφίλ μου»** ακόμη και με μερικές απαντήσεις.
4. Από **«Εξαγωγή / Εισαγωγή»** κράτησε αντίγραφο JSON. Οι σημειώσεις και απαντήσεις αποθηκεύονται τοπικά στον browser, όταν υποστηρίζεται η τοπική αποθήκευση.

**Για αξιόπιστη αποθήκευση σε iPhone/Safari, προτιμάται εγκατάσταση σε σταθερό HTTPS web origin** (π.χ. με στατικό hosting) αντί για άνοιγμα του HTML από εφαρμογή προβολής αρχείων. Αν υπάρχει ένδειξη περιορισμένης αποθήκευσης, χρησιμοποίησε εξαγωγή JSON.

## Επτά υποσυστήματα με κοινή συνεδρία

- **135 σταθερές ερωτήσεις** τράπεζας v2: 12 γενικές, 105 αναλυτικές, 18 trade-offs, σε 12 κατηγορίες.
- **20 MaxDiff** κάρτες, 16 ιδιότητες, 4 ιδιότητες/κάρτα, 5 εμφανίσεις/ιδιότητα. Πρόκειται για απλές καταμετρήσεις Best–Worst, όχι βαθμονομημένο ψυχομετρικό μοντέλο.
- **12 σενάρια** σχέσης με πρακτικά υποθετικά διλήμματα.
- **12 αξιολογήσεις σημαντικότητας** 0–5, ανεξάρτητες από προτίμηση A/B.
- **15 φωτογραφικές συγκρίσεις** με *σταθερά ζεύγη που εισάγει ο χρήστης*. Τα αρχικά εγκεκριμένα εικόνα-assets δεν ήταν διαθέσιμα κατά την ανάκτηση, άρα δεν περιλαμβάνονται. Για κάθε ζευγάρι απαιτούνται δύο εικόνες. Οι εικόνες αποθηκεύονται σε IndexedDB αν υποστηρίζεται.
- **50 προαιρετικές ερωτήσεις στοχασμού** για συζήτηση και σημειώσεις.
- **Beauty Intelligence** με 16 σταθερές ερωτήσεις αισθητικής, 12 συνθετικά πορτρέτα, 12 αξιολογήσεις έλξης, 24 μοναδικές συγκρίσεις και 3 επανελέγχους συνέπειας. Τα ίδια ακριβώς 12 πορτρέτα είναι ενσωματωμένα στο Super Test, χωρίς ανέβασμα εικόνων.

Η ενιαία αναφορά περιλαμβάνει προτιμήσεις ανά τομέα, τεκμήρια με ID ερώτησης, MaxDiff, σενάρια, διασταύρωση διαφορετικών υποτεστ, αβεβαιότητες και ιστορικές συγκρίσεις. Οι ερωτήσεις στοχασμού **δεν είναι προϋπόθεση** για να εμφανιστεί αναφορά.

### Σύνδεση με παλιές εκδόσεις

Υπάρχει εισαγωγή από πλήρες Super Test v1 JSON και από τράπεζα v2 με *ακριβή, κοινά IDs* (`G-EMO`, `D-VIS-01` κλπ.). Για παλιές απαντήσεις με διαφορετικά/αριθμητικά IDs **δεν γίνεται αυθαίρετη αντιστοίχιση**: το αρχικό payload αποθηκεύεται σε ξεχωριστό πεδίο `legacyImports` χωρίς να επηρεάζει την ανάλυση. Η ένωση των αποτελεσμάτων της αρχικής έκδοσης απαιτεί χειροκίνητα ελεγμένη αντιστοίχιση ερωτήσεων.

## Εκτέλεση δοκιμών / build

Απαίτηση: Node.js 20+ και προαιρετικά Python Playwright + Chromium για UI smoke tests.

```bash
npm run build:data  # αναδημιουργεί την ελεγμένη 135-item τράπεζα και τα extension modules
npm run check       # 15 unit tests και standalone HTML build
python tests/browser_smoke.py
python tests/browser_full_flow.py
```

Το **`index.html`** είναι το ready-to-use artifact. Τα `src/`, `data/`, `tests/` και `build*.mjs` αποτελούν τον επεκτάσιμο κώδικα. Το site είναι privacy-first: η εφαρμογή δεν διαθέτει backend και δεν στέλνει απαντήσεις σε εξωτερικό server. Όποιος αποκτήσει αντίγραφο ενός JSON export μπορεί να δει τα δεδομένα του — φρόντισε τα αρχεία εξαγωγής σαν ιδιωτικά.

## Όρια / επόμενα βήματα

- Υπάρχει προκαθορισμένο σταθερό φωτογραφικό dataset 12 συνθετικών πορτρέτων στο Beauty Intelligence, αλλά δεν υπάρχει ψυχομετρικά επικυρωμένο predictive model. Οι 15 θέσεις `VP-*` με εικόνες χρήστη παραμένουν χωριστό υποσύστημα.
- Η αναφορά δείχνει ό,τι υποστηρίζεται από τις πραγματικές απαντήσεις, όχι «πιθανότητα συμβατότητας».
- Το UI έχει δοκιμαστεί αυτοματοποιημένα σε headless Chromium για mobile viewport. Δεν έχει γίνει φυσικό QA σε iPhone/Safari ή end-to-end έλεγχος πραγματικής IndexedDB αποθήκευσης εικόνων στον Safari.
- Συμβατότητα/αντιστοίχιση της αρχικής έκδοσης των 135 ερωτήσεων παραμένει ανοικτή εξάρτηση, εφόσον διαφορετική από την τράπεζα v2.
